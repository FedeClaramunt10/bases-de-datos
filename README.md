# Bases de Datos

Trabajos prácticos de la materia Bases de Datos de la Tecnicatura en Análisis de Datos e Inteligencia Artificial: diseño de esquemas relacionales, modelado MER/MER y SQL (DDL, DML, consultas y joins).

## Contenido

### `sql/`

| Archivo | Contenido |
|---------|-----------|
| `tp1_pizzeria.sql` | Diseño y carga de base de datos de una pizzería. |
| `tp2_citas_medicas_entrega.sql` | Entrega final del TP2: base de datos de citas médicas. |
| `tp2_citas_medicas_v1.sql` / `v2.sql` / `v3.sql` | Iteraciones de trabajo del TP2. |
| `tp_aplicacion_viajes.sql` | TP de aplicación: base de datos de viajes en transporte. |
| `parcial2_refugio.sql` | Solución del parcial: esquema de un refugio. |
| `huertocomunitario.sql` | Base de datos de huerto comunitario. |

### `entregas/`

- `TP2_BBDD_Claramunt_Federico.pdf` / `.docx` — informe del TP2 (citas médicas).
- `Trabajo_de_Aplicacion.pdf` + `Analisis_e_inferencias.docx` + `Presentacion_TP_Aplicacion.pptx` — informe y presentación del TP de aplicación (viajes).
- `Parcial2_Claramunt_Federico.docx` — resolución del parcial.

### `datos/` y `mer/`

- `viajes_transporte.csv` — datos del TP de aplicación.
- `tp2_diagrama.png` — diagrama del esquema de citas médicas.
- `mer_festival_musica.html` / `mer_festival_musica_v2.html` — representación MER de un festival de música y danza (páginas HTML autocontenidas).

## Temas cubiertos

- Modelado entidad-relación (MER) y transformación a modelo relacional
- SQL: `CREATE TABLE`, `INSERT`, `UPDATE`, `DELETE`
- Consultas con `JOIN`, agregaciones y subconsultas
- Integridad referencial y claves foráneas
